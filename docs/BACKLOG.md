# Backlog

Ideas for consideration in this repository. The system of record is this file.
IDs are unique here, never reused, and use the form BL.NN (BL.01, BL.02, …).

| Field | Allowed values |
|---|---|
| Source | owner, team |
| Status | proposed, considering, accepted, rejected, parked |
| Priority | 5 (high) … 1 (low). This is idea priority, not incident scoring. |
| Linked issue | optional GitHub issue number, or empty |

Do not put personal details, credentials, or private household, health, school, finance, or location information in this file.
