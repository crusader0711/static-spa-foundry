# signal-spa

SIGNAL — terminal-inspired DevOps dashboard on the static-spa v1.TW engine.
Dark-only, neon green, JetBrains Mono. 12 pages: Overview, Servers, Containers,
Deploys, Kubernetes, Incidents, Logs, Status, Databases, Security, API, Costs.

v0.1 = full UI with MOCK data. Live telemetry is gated on
[ACCESS_REQUIREMENTS.md](ACCESS_REQUIREMENTS.md) (data sources, IAM/NAS/
GitHub access items, and the no-secrets-in-static-sites architecture).

Ctrl/⌘+K command palette · sidebar layout ≥940px · original implementation
(design language inspired by, not copied from, commercial Signal template).

Mock IPs use RFC 5737 documentation ranges (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24). Formal README to follow from templates/PROJECT_README_TEMPLATE.md.
